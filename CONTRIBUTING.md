# Contributing

Keep the core skill concise. Put substantial task-specific details in references and link them from SKILL.md.

For behavioral changes, include a realistic request, expected behavior, and observed behavior. Do not submit private writing samples, personal profiles, secrets, or unauthorized material.

## Validation

1. Check that SKILL.md has valid YAML frontmatter, the name is humanwrite, and the description is specific.
2. Check relative links and confirm the installable folder contains all referenced resources.
3. Run relevant scenarios from examples/acceptance-scenarios.md in a compatible assistant. Record the model and actual results.
4. Pay particular attention to direction selection, clear user intent, counterarguments versus contradictions, and unverified evidence.

Structural validation does not replace behavioral evaluation. Evaluate decisions and meaning rather than matching exact wording.
